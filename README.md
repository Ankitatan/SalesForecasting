## 📌 Project Overview

This project predicts future sales using historical retail data by applying machine learning techniques. It includes data preprocessing, feature engineering, exploratory data analysis (EDA), model training, evaluation, and deployment through a Streamlit web application.

The objective is to help businesses make data-driven inventory and sales planning decisions.

- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)

- Machine Learning Model Training
- Sales Prediction

## 💻 Installation

Clone the repository

```bash
git clone https://github.com/Ankitatan/SalesForecasting.git
```

Navigate to the project

```bash
cd SalesForecasting
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the Streamlit application

```bash
streamlit run app.py
```
